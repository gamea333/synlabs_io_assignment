P1 — Cost-efficient RAG on LanceDB: ingestion and query path

flowchart TB
  subgraph ING[Ingestion - python -m app.cli ingest / POST /ingest]
    direction TB
    A[Corpus folder
PDF / HTML / MD] --> B[Loaders
pypdf page-aware
BeautifulSoup boilerplate strip
MD cleanup]
    B --> C[Token chunker cl100k
size 256, overlap 32]
    C --> D{file hash + chunk config
+ model unchanged?}
    D -- yes --> SKIP[skip file
no re-embedding]
    D -- no --> E[Embed: bge-small-en-v1.5
384-d, local ONNX]
    E --> F[(LanceDB table on disk
vector + text + source, doc_type,
page, chunk_idx, doc_hash
delete stale, merge_insert on chunk_id)]
  end
  subgraph QRY[Query - POST /query]
    direction TB
    Q[question, k, doc_type?, source?] --> QE[Embed query
bge query prefix]
    QE --> R[Top-k cosine search
metadata PRE-filter]
    F --> R
    R --> G1{Gate 1: any chunk
score >= MIN_SCORE 0.50?}
    G1 -- no --> NO1[NO RELEVANT CONTEXT
refuse, LLM not called, 0 tokens]
    G1 -- yes --> P[Prompt: numbered passages
+ cite every sentence n
+ exact refusal string]
    P --> L[LLM gpt-oss-20b via Groq
OpenAI-compatible]
    L --> G2{Gate 2: model returned
refusal string?}
    G2 -- yes --> NO2[NO RELEVANT CONTEXT
refuse: llm_insufficient_context]
    G2 -- no --> CIT[Map n to chunk_id, source,
page, score]
    CIT --> OUT[JSON: answer + citations]
    NO1 --> LOG[logs/queries.jsonl
latency embed/search/llm/throttle
chunks retrieved/used, tokens]
    NO2 --> LOG
    OUT --> LOG
  end
  style NO1 fill:#fde2e1,stroke:#c0392b
  style NO2 fill:#fde2e1,stroke:#c0392b
  style F fill:#e3f0fb,stroke:#1f3b57
Red boxes = "no relevant context" branch. Defaults from .env: CHUNK_SIZE=256, CHUNK_OVERLAP=32, TOP_K=5, MIN_SCORE=0.50.
